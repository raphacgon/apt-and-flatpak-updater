#apt-and-flatpak-updater
A simple Bash script to automate 'apt' and 'flatpak' updates and upgrades on compatible Linux systems.

#HowToUseIt

Once you've downloaded the script, make it executable and run* it on your terminal.
```bash
chmod +x update.sh
./update.sh
```
*Note:This script requires root privileges to run the 'apt' commands. You WILL be prompted to enter your 'sudo' password during execution.
